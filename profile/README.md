# metadatastician

Shared work. This organisation holds what has more than one author or more than one user:

- **Joint research** — principally with Joshua Jewell (e.g. MetaManifold).
- **Estate infrastructure** — the tooling the research and the studio both run on: estate operations,
  hypatia / gitbot-fleet, cicd-squabbler, BoJ server, the API adapter, proof tooling.

Single-author scholarship (the type family, languages, databases, standards) lives at
[hyperpolymath](https://github.com/hyperpolymath); the game studio at
[Invisible Door Studios](https://github.com/invisible-door-studios).

This organisation runs on the GitHub Education Team benefit, which is for courses, clubs and
non-profit research — so nothing commercial lives here.
