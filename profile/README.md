## Licensing

This estate uses three licences deliberately, not by accident:

- **MPL-2.0** — the default. Work meant to be built upon and adopted widely.
- **AGPL-3.0-or-later** — games, and projects co-developed with family. AGPL §13 reaches
  network deployment, which is how a game is most often encountered.
- **CC-BY-SA-4.0** — prose and documentation throughout.

A repository's own `LICENSE` file is authoritative. Licences are never changed by
automation.
