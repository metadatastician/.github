# Support

| What you have | Where it goes |
|---|---|
| A bug | An issue on the relevant repository |
| A feature idea | An issue, or a discussion if it is open-ended |
| A question about usage | A discussion on the repository |
| **A security vulnerability** | **Not an issue** — see [`SECURITY.md`](SECURITY.md) |
| Something about the organisation as a whole | `sudo@metadatastician.art` |

## Expectations

This estate is maintained by one person alongside other work. Support is best-effort and
there is no service-level agreement. Issues are read; they are not always answered quickly.

A well-formed report — what you did, what happened, what you expected — will nearly always
get a faster and better response than a vague one.
